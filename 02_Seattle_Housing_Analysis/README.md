# Seattle Housing Data Analysis

## Overview

Explores a real-world housing dataset through data cleaning, grouped statistics, distributions, and relationships among property characteristics.

### Research question

> What patterns appear in Seattle home prices and property characteristics, and which variables are most useful for explaining differences in price?

## Technical skills

**Python · pandas · NumPy · Matplotlib · exploratory data analysis · statistics · data visualization**



## Repository contents

- `main.py` — code-only version of the analysis.
- `seattlehousing.ipynb` — interactive notebook version.
- Dataset file(s) — the data required by the original analysis.

## What I did

- Performed exploratory data analysis on a large Seattle housing dataset with pandas and NumPy, examining distributions, grouped statistics, and relationships among property characteristics.
- Created visualizations to communicate how variables such as size and location-related features relate to housing prices.
- Structured a reproducible analysis workflow from raw CSV data to statistical summaries and visual findings.
