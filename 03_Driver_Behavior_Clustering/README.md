# Driver Behavior Clustering

## Overview

Uses exploratory analysis and clustering to investigate whether drivers can be separated into meaningful behavioral groups without predefined labels.

### Research question

> Can unsupervised learning reveal distinct groups of driving behavior from measured driving features?

## Technical skills

**Python · pandas · NumPy · Matplotlib · exploratory data analysis · statistics · data visualization**

 · unsupervised learning · clustering

## Repository contents

- `main.py` — code-only version of the analysis.
- `clustering.ipynb` — interactive notebook version.
- Dataset file(s) — the data required by the original analysis.

## What I did

- Applied unsupervised clustering to driving-behavior data in Python to identify groups of observations with similar feature profiles.
- Used exploratory statistics and visualizations to examine feature distributions and interpret differences between resulting clusters.
- Translated an unlabeled behavioral dataset into interpretable segments, demonstrating an end-to-end introductory machine-learning workflow.
