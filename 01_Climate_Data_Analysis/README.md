# Climate Data Analysis & Time-Series Statistics

## Overview

Analyzes more than a century of monthly climate observations and applies descriptive statistics, visualization, and moving-average smoothing to identify long-term patterns.

### Research question

> How have long-term temperature and precipitation patterns changed, and what can smoothed time-series statistics reveal about those trends?

## Technical skills

**Python · pandas · NumPy · Matplotlib · exploratory data analysis · statistics · data visualization**
 · time-series analysis


## Repository contents

- `main.py` — code-only version of the analysis.
- `project_3.ipynb` — interactive notebook version.
- Dataset file(s) — the data required by the original analysis.

## What I did

- Analyzed 1895–2022 monthly temperature and precipitation records in Python using pandas and NumPy, summarizing long-term climate patterns with descriptive statistics and visualizations.
- Applied moving-average/time-series smoothing to reduce short-term noise and make long-term trends easier to interpret.
- Built reusable statistical and visualization functions to streamline exploratory analysis across large historical datasets.
