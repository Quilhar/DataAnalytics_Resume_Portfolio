# Boston Crime Data Visualization

## Why this is included
Useful visualization-heavy project working with a large public dataset and examining temporal/geographic crime patterns.

## Skills demonstrated
Python, pandas, NumPy, Matplotlib, Plotly, data visualization, exploratory data analysis

## Files
- `boston_crime.ipynb` — original interactive notebook, cleaned to use local dataset paths.
- `main.py` — code-only version for quick review.
- `crime.csv` — project dataset.
