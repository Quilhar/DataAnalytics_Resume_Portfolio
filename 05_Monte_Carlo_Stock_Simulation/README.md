# Monte Carlo Stock-Market Simulation

## Why this is included
Shows probabilistic simulation rather than only descriptive analysis, including return distributions and Monte Carlo estimation.

## Skills demonstrated
Python, NumPy, pandas, Matplotlib, probability, Monte Carlo simulation, statistical modeling

## Files
- `monte_carlo_simulation_pt1.ipynb` — original interactive notebook, cleaned to use local dataset paths.
- `main.py` — code-only version for quick review.
- `yearly_sp_data.txt` — project dataset.
